To get started, install NetBird and log in using your email account. After that you should be connected. If you have further questions check out our Installation Guide

Install with Command-line

1
Terminal
curl -fsSL https://pkgs.netbird.io/install.sh | sh
2

Run NetBird and log in the browser

Terminal
netbird up --management-url https://netbird-stg.sleek.com
1

Add our repository

Terminal
sudo apt-get update
sudo apt install ca-certificates curl gnupg -y
curl -sSL https://pkgs.netbird.io/debian/public.key | sudo gpg --dearmor --output /usr/share/keyrings/netbird-archive-keyring.gpg
echo 'deb [signed-by=/usr/share/keyrings/netbird-archive-keyring.gpg] https://pkgs.netbird.io/debian stable main' | sudo tee /etc/apt/sources.list.d/netbird.list
2

Install NetBird

Terminal
sudo apt-get update
# for CLI only
sudo apt-get install netbird
# for GUI package
sudo apt-get install netbird-ui
3

Run NetBird and log in the browser

Terminal
netbird up --management-url https://netbird-stg.sleek.com

Install on Ubuntu

1

Install Docker

Official Docker Installation Guide
2

Run NetBird container

Terminal
docker run --rm -d \
  --cap-add=NET_ADMIN \
  -e NB_SETUP_KEY=SETUP_KEY \
  -v netbird-client:/var/lib/netbird \
  -e NB_MANAGEMENT_URL=https://netbird-stg.sleek.com \
  netbirdio/netbird:latest
